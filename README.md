# omniguard_ai
OmniGuard AI is an autonomous, multi-hazard computer vision system and real-time public safety monitoring hub designed for smart city infrastructure. Built using Python, OpenCV, NumPy, and Ultralytics YOLOv8 (yolov8n.pt), OmniGuard AI processes live video feeds at the edge with ultra-low latency to detect immediate hazards and emergencies.
